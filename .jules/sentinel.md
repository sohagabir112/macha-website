## 2024-05-24 - IDOR Vulnerabilities in Server Actions
**Vulnerability:** Missing authentication checks and improper user scoping in `app/cart/actions.ts` (`updateCartItem` and `removeCartItem`). Attackers could manipulate any cart item by specifying an arbitrary `itemId`, as the database query only matched `id` without verifying the item belonged to the authenticated user.
**Learning:** Next.js Server Actions execute on the server but can be invoked by anyone if exposed to the client. Without explicit authentication checks (`supabase.auth.getUser()`) and scoping database queries to the authenticated user (`.eq('user_id', user.id)`), Server Actions become susceptible to Insecure Direct Object Reference (IDOR) attacks, allowing unauthorized access or modification of other users' data.
**Prevention:** Always authenticate the user at the beginning of a sensitive Server Action. Always scope database mutations (UPDATE, DELETE) and retrievals (SELECT) involving user-specific data to the authenticated user's ID to prevent cross-account manipulation.
